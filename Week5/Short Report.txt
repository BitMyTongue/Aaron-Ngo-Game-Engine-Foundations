For this assignment, I added phong lighting to the minecraft dirt block I had 
from assignment 4 to simulate shading. I updated the vertex data to include 
normals, along with the positions and texture coordinates I already had. Then 
I updated the vertex and fragment shader codes following the code that was 
provided on Blackboard, but kept my texture coords in order to keep my minecraft 
dirt block rather than a solid color block. 

Since a majority of the lighting code was provided, the biggest challenge I faced 
was making the project interactive. Adding the manual cube rotation with mouse, 
and lighting movement with WASD took some time to figure out. Essentially, we're 
checking for keyboard input each frame in OnUpdateFrame(), and updating the light 
position accordingly. W/S moves the light up and down, while A/D moves it left or 
right. To move the object, I added an OnMouseMove() method, which starts at a 
defined position when initally moved, then the change in mouse position (delta) is 
multiplied by the sensitivity and applied to the cube's rotation.
